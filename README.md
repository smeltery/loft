Marketing site for **loft**, a Finder drive that keeps terabytes in the cloud
and zero bytes on your Mac.

## Quick start

```bash
flox activate
bun install --frozen-lockfile
bun run dev
```

`bun run ci` is the same gate GitHub Actions and the git hooks run.
